# 跨电脑盲测说明

## 目的

验证另一台电脑在没有当前对话上下文、没有看过旧答案的情况下，能否只依靠仓库里的 Skill 稳定完成任务。

## 准备

1. 在另一台电脑登录有权访问该私有仓库的 GitHub 账号。
2. 克隆整个私有仓库，并用 Codex 打开项目目录。
3. 请 Codex 安装仓库中的 `ctcsol-interview-coach` Skill；安装后开启一个新任务测试。
4. 不向测试任务提供本仓库 `tests/results/` 中的答案。

## 第一轮提示词

```text
请使用 $ctcsol-interview-coach 盲测这份材料。
先核对材料、估计外国中文学习者的水平，
再给出 2—3 个候选教学点、理由和风险。
在我确认教学点以前，不要生成说课和试讲。
```

随后上传一张此前没有写入仓库的真实材料截图。

## 确认后的提示词

```text
用推荐点。请生成3分钟说课参考稿、关键词提纲、
7分钟试讲逐字参考稿、分镜和动态板书。
```

## 验证清单

- 是否准确转写截图，模糊内容有没有明确标记。
- 是否发现材料类型与 Skill 范围不匹配的情况。
- 是否根据材料推断学习者水平，而不是默认 HSK 2。
- 候选点是否来自题面，而且彼此真正不同。
- 是否在用户确认前停止。
- 语法规则和核心例句是否准确、自然。
- 说课与试讲的对象、目标、例句是否一致。
- 是否包含模拟学生产出、具体反馈、纠错和动态板书。
- 分镜是否连续覆盖 00:00—07:00。
- 真人朗读是否接近3分钟和7分钟。

## 回传记录

保存：原始截图、第一轮回答、确认后的完整回答、模型名称、实际朗读时长、发现的问题。不要只保存最终改好的版本。
