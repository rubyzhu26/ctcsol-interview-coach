# 测试 01B：确认“用推荐点”后的完整草稿

## 一、材料与选点决定

- 学习者假设：约 HSK 2–3 的成年中文学习者，已经会常见形容词和基本购物问答；这是根据材料作出的中等置信度假设。
- 确认教学点：购物语境中的“有点儿 + 形容词”与“形容词 + 一点儿”。
- 可观察目标：学生能先用“有点儿……”描述商品当前不合适之处，再用“……一点儿”说出希望改变的方向，并完成一轮顾客—店员对话。
- 主动舍弃：数量结构“一点儿 + 名词”、全部褒贬限制、其他“一点儿”用法和完整比较句体系。
- 核心例句：这件外套有点儿大。有没有小一点儿的？这件颜色有点儿深，我想要浅一点儿的。

## 二、3 分钟说课参考稿

各位考官好，下面我对这段材料进行说课。

本课的教学对象暂定为约 HSK 二到三级的成年中文学习者。他们已经掌握“大、小、深、浅”等常见形容词，也能进行简单的购物问答。根据材料中连续出现的“有点儿大—小一点儿”和“有点儿深—浅一点儿”，我选择购物语境中“有点儿加形容词”和“形容词加一点儿”作为本次教学内容。

本课有两个教学目标。第一，学生能够听懂这两种形式在语境中的不同作用：前者描述当前感受到的程度，材料中带有不太合适的意味；后者表达希望程度朝某个方向改变。第二，学生能够在服装店情境中，用这两种形式完成“说明问题—提出要求”的话轮。

教学重点是两种形式的语序和交际功能。教学难点是学生不仅要把“一点儿”放在正确位置，还要选择自然的变化方向，例如“大—小一点儿、深—浅一点儿”，而不是机械替换。

教学时，我先出示两件大小不同的外套，创设服装店情境，让学生观察顾客为什么不满意。接着回到材料，通过两组原句引导学生发现：描述当前感受时说“有点儿加形容词”，提出调整方向时说“形容词加一点儿”。我会随讲解逐步完成对比板书。然后安排图片选择和句子补全，让学生进行控制性操练，并针对“衣服大有点儿”等语序错误进行重述和自我修正。之后，学生根据不同服装卡片完成半控制练习，最后以顾客和店员的角色完成真实购物对话。课堂结束前，我用一个新情境快速检测学生能否迁移使用。

完整课时预计四十五分钟，包括词汇复习、课文理解、语言点教学、任务活动和总结。本次七分钟试讲展示其中语言点发现、操练和交际活动的核心片段。

我的说课完毕，谢谢各位考官。

### 说课关键词提纲

- 对象：约 HSK 2–3；成年；已会形容词和购物问答
- 内容：有点儿 + Adj / Adj + 一点儿；购物调整
- 目标：听懂不同作用；完成“问题—要求”话轮
- 重点：语序 + 功能
- 难点：自然变化方向，不机械替换
- 步骤：实物导入—原句发现—对比板书—控制操练—卡片选择—角色活动—迁移检测
- 课时：完整 45 分钟；试讲展示核心 7 分钟

## 四、7 分钟逐字参考稿

同学们好。请看，这里有两件外套。我们现在在哪儿？……对，在服装店。顾客试了第一件，可是没有马上买。为什么？……我听到有同学说“衣服太大”。对，大小不太合适。如果我们想说得委婉一点儿，可以怎么说？

请看材料第一句：“这件外套有点儿大。”【板书：现在的感受　有点儿 + 形容词】这里的“有点儿大”是在说顾客现在的感受，这个大小不太合适。大家跟我说一次：“这件外套有点儿大。”……很好，“有点儿”放在了形容词“大”的前面。

顾客想换一件，他说：“有没有小一点儿的？”【板书：希望改变　形容词 + 一点儿】现在顾客希望衣服怎样变化？……对，从大变小，所以说“小一点儿”。请大家看位置：描述现在，“有点儿”在形容词前；希望改变，“一点儿”在形容词后。

再看第二组：“颜色有点儿深，我想要浅一点儿的。”现在的颜色怎么样？……有点儿深。希望怎样改变？……浅一点儿。非常清楚，你不但找到了两种形式，也找到了正确的变化方向。【板书：大 → 小；深 → 浅】今天我们只学习这种描述商品并提出调整的用法，不讨论“一点儿水”中的“一点儿”。

下面看图片。这条裤子太长了。请用“有点儿”说一说。……我听到一个回答：“裤子长有点儿。”我们再看板书，“有点儿”应该放在哪儿？……对，放在形容词前。请完整地再说一次。……“这条裤子有点儿长。”这次语序正确。现在你想换短一些的，怎么说？……“我想要短一点儿的。”很好，“短一点儿”说出了改变方向。【板书补充：长 → 短】

再来一组。这双鞋穿起来不舒服，因为太紧。小林，请说第一句。……“这双鞋有点儿紧。”对，这是现在的感受。你希望店员拿什么样的？……“有没有松一点儿的？”很好，两句话已经连起来了。

现在每个人选择一张商品卡。假设你拿到的衬衫价格是五百元，旁边有三百元的。你会怎样告诉店员？……“这件衬衫有点儿贵，我想要便宜一点儿的。”说得很完整：“有点儿贵”说明现在的问题，“便宜一点儿”说明你的要求。【板书补充：贵 → 便宜】

下面我们来做服装店角色练习。A 是顾客，卡片上写着商品不合适的地方；B 是店员，要听清顾客的要求，再推荐一件。先听我和一位同学示范。

“您好，我想看看这件外套。”……“您试试吧。”……“这件颜色有点儿深，有没有浅一点儿的？”……“有，您看看这件。”很好，顾客说明了问题和方向，店员也作出了回应。

第二组，开始。……我听到顾客说：“这件有点儿大，有没有小一点儿的？”店员说：“有，您试试这件。”这轮对话的目标语言和回应都完整。请交换角色，再选择“长—短”或“贵—便宜”完成一轮。……

最后换一个新场景。手机上的字太小，看不清。请用今天的两个形式说一句话。……“字有点儿小，请调大一点儿。”完全正确：“有点儿小”描述现在，“大一点儿”说明希望改变的方向。【板书最终例句：字有点儿小 → 调大一点儿】

今天我们学会了先用“有点儿加形容词”描述当前感受，再用“形容词加一点儿”表达希望怎样改变。课后请观察生活中的一件东西，准备一组“现在怎么样—希望怎样改变”的句子。好，下课。

## 五、最终板书

```text
                 服装店：说明问题 → 提出要求

现在的感受                         希望改变
有点儿 + 形容词                   形容词 + 一点儿

外套有点儿大          →           小一点儿
颜色有点儿深          →           浅一点儿
裤子有点儿长          →           短一点儿

迁移：字有点儿小      →           调大一点儿
```
