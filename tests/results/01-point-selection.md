# 测试 01A：候选点确认关卡

## 材料核对

文字清晰，角色为服装店顾客与店员。顾客两次描述商品不合适，并提出更换方向；没有需要补认的片段。

## 学习者水平估计

- 暂估：约 HSK 2–3 之间，置信度中。
- 依据：以“外套、大小、颜色、试试”等日常购物词汇为主；句子较短；出现“有点儿 / 形容词 + 一点儿”、“可是”以及省略中心语的“……的”。
- 限制：材料没有注明教材和 HSK 版本，因此这里只能作为备课假设，不能认定其官方等级。

## 候选教学点

### 1. “有点儿 + 形容词”与“形容词 + 一点儿”｜语法

- 材料原句：“外套有点儿大”“小一点儿的”“颜色有点儿深”“浅一点儿的”。
- 最小可教用法：先描述当前不太合适的程度，再表达希望改变的方向。
- 适合之处：题面证据最集中，同一购物情境中两种形式自然成对；容易设计观察、替换、纠错、角色扮演和对比板书。
- 风险：不能教成“有点儿后面只能跟贬义形容词”；本课应排除数量结构“一点儿 + 名词”。
- 结论：优先，置信度高。

### 2. “有没有 + 形容词 + 一点儿 + 的？”｜语法/交际句式

- 材料原句：“有没有小一点儿的？”
- 最小可教用法：在商店询问是否有更符合要求的同类商品。
- 适合之处：交际目的明确，可以直接进行店员与顾客角色练习。
- 风险：题面只有一个完整实例；需要解释“的”代替商品，还可能牵涉比较基准，七分钟内容容易旁逸斜出。
- 结论：可选，置信度中。

### 3. “描述不合适 → 提出更换要求”｜交际功能

- 材料原句：两组“有点儿……”后接“小/浅一点儿”。
- 最小可教用法：顾客礼貌说明商品问题，并告诉店员希望怎样调整。
- 适合之处：最贴近真实任务，角色活动自然；即使不强调术语，学生也能完成话轮。
- 风险：如果没有固定语言支架，试讲可能只剩泛泛的购物会话，难以展示清楚的讲解和纠错。
- 结论：可选，置信度中高。
