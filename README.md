# CTCSOL 说课试讲陪练

当前版本：v0.1 internal alpha（2026-09-02）

## 现在能做什么

1. 接收一段清晰的初级面试材料文字；流程已写入截图核对规则，但截图测试留到下一轮。
2. 估计外国中文学习者的水平或范围，并说明证据与不确定性。
3. 给出 2–3 个候选教学点、最小可教用法、适合之处和风险。
4. 等考生确认教学点。
5. 生成 3 分钟说课参考稿与关键词提纲。
6. 生成 7 分钟试讲逐字参考稿、分镜、模拟互动、纠错和动态板书。
7. 根据考生的实际用时或转写进行复盘。

## 对话入口

```text
使用 $ctcsol-interview-coach 分析下面的考试材料。
先核对材料、估计学习者水平，再给我 2–3 个候选教学点和理由；
在我确认前不要生成说课和试讲。

【粘贴文字或上传截图】
```

收到候选点后可直接回复：

```text
用推荐点。请生成 3 分钟说课参考稿、关键词提纲、
7 分钟逐字参考稿、分镜和动态板书。
```

练习后可继续回复：

```text
我的说课用了 3 分 25 秒，试讲用了 7 分 40 秒。
下面是我的转写稿，请按必须改、表现优化、个人风格复盘，
并只给我下一轮最优先练的一个问题。
```

## 当前边界

只覆盖初级面试的 3 分钟说课与 7 分钟试讲。暂不覆盖中高级、中外文问答、登录支付、独立网站、完整 HSK 1–6 语法库或通过率承诺。
