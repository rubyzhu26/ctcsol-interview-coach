# 陪练路线卡

## 备课路线（不计入七分钟）

```text
看材料 {status}
→ 找可以教的语言点 {status}
→ 选定本课重点 {status}
→ 想清楚是什么意思、怎么用 {status}
→ 准备图片、例句和练习 {status}
```

## 七分钟试讲路线（正式课堂）

```text
开场进入情境 {status}
→ 把新句子带出来 {status}
→ 讲清意思、说法和使用场合 {status}
→ 教师带着学生练 {status}
→ 学生换内容自己说 {status}
→ 检查、纠正并总结 {status}
→ 需要时布置作业 {status}
```

第一次进入七分钟试讲前，用一句话解释每个环节：

- **开场进入情境：**用图片、视频、动作或问题进入话题。
- **把新句子带出来：**让目标表达自然出现。
- **讲清怎么用：**说明意思、形式和使用场合。
- **带着学生练：**学生根据教师提供的词语或图片说。
- **让学生自己用：**学生换成自己的真实信息表达。
- **检查和纠正：**确认学生能否独立使用，并处理错误。
- **总结和作业：**简短回顾，需要时布置任务。

状态：

- `✓` 已经完成
- `●` 当前正在练
- `○` 尚未开始
- `△` 基本成立，有小问题留待复查

使用要求：

- 用户从材料分析开始时先显示备课路线；第一次从备课转入试讲时，再显示七分钟试讲路线和简短说明。用户已选好教学点并直接要求试讲时，直接显示七分钟试讲路线。
- 明确告诉用户：路线只是导航，不限制每次必须讲多长；用户可以只讲一句、连续讲多个环节或直接完整试讲。
- 未开始的环节只显示名称和状态，不泄露答案或具体设计。
- 用户一次覆盖多个环节时同时更新，不按预设片段把用户拉回。
- 板书随课堂逐步形成，不单独列成最后一关。
