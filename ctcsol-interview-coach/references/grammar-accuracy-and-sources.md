# 语法准确性与来源规则

## 来源优先级

1. 当前考题材料与最新官方考试要求
2. 用户提供且版本可确认的权威语法书或教材
3. 标明版本的 HSK 语法索引
4. 已经人工测试通过的本 Skill 语法卡
5. 模型临时生成的解释

来源冲突时，说明冲突并缩小结论。语法书适合作为 reference，但不要整本塞入上下文；只提取与当前教学点有关的规则、例句和限制。

## 出稿前检查

- 形式：成分顺序、可替换成分、否定或疑问形式是否准确？
- 意义：表达什么，不表达什么？
- 条件：受语境、词类、主观性或搭配限制吗？
- 近义区别：考试材料是否真的需要对比？
- 例句：母语者自然吗，且能构成真实任务吗？
- 分级：解释和例句是否比学生水平难？
- 范围：七分钟是否只讲一个可验证的小目标？

## 暂定语法卡：有点儿 与 形容词 + 一点儿

### 最小教学范围

- `有点儿 + 形容词`：描述说话人当前感受到的某种程度，常带不如意或需要调整的语境，但不能教成“后面只能放贬义形容词”。
- `形容词 + 一点儿`：在比较、选择或调整的语境中，表示希望程度朝某个方向变化。
- 本课不讲数量结构 `一点儿 + 名词`。

### 可用语境链

- 这件衣服有点儿大。有没有小一点儿的？
- 这双鞋有点儿紧。我想试试宽松一点儿的。
- 音乐有点儿响。可以小声一点儿吗？
- 空调有点儿冷。能调高一点儿吗？

### 易错提醒

- 不把规则简化为 `有点儿 + Adj / Adj + 一点儿` 后就停止解释；必须补上语境和意义。
- 不使用语义牵强的对比，如“鸡翅有点儿辣，甜一点儿就好了”。
- 不使用不自然表达，如“房间很冷，可以热一点儿吧”。
- 板书突出“当前感受 → 希望改变方向”，避免堆很多孤立形容词。

## 首题语法卡：把 + 物品 + 放在/放到 + 地点

### 材料依据

CTCSOL 官网初级面试样题出现“咱们把自行车放在这儿”“你先把书包放到旁边的地上”。本卡只核验这份材料需要的最小用法，不概括整个把字句系统。

### 最小教学范围

- 形式：`主语 + 把 + 物品 + 放在/放到 + 地点`。
- 意义：处置一个语境中可识别的物品，并说明“放”这一动作后的地点结果。
- “放在 + 地点”和“放到 + 地点”在本课都提供地点结果；“放到”更明显地呈现到达的终点。不得教成所有语境中完全等同。
- 本课中“放”后必须补出 `在/到 + 地点`，不能停在 `*把书包放`。
- 不扩展其他动词、否定位置、能愿动词、复杂趋向补语或整个把字句系统。

### 自然例句

- 请把手机放在包里。
- 请把水瓶放在桌子上。
- 你把雨伞放到门口吧。
- 咱们把地图放在书包里。

### 典型偏误与处理

- `*你把放书包到地上。`：用顺序线索提醒“把后面先说什么”，再请学生完整重说。
- `*你把书包放。`：追问“放在哪儿”，学生补全后再完整重说。
- `*你书包把放在地上。`：用板书位置或手势提示“把”在主语之后，再请完整重说。

### 易错提醒

- 不把“把”简单等同于英语或其他语言中的固定介词。
- 不只让学生背结构，必须让其理解和说出动作后的地点结果。
- 不把“把”后的名词绝对化为只能是语法意义上的定指；本课只说它在当前语境中应当是说话双方可识别的物品。
- 不为了展示知识而加入本题不需要的完整把字句限制。
