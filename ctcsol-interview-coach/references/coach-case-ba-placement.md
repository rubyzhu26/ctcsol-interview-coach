# 首题教练底稿：把物品放在/放到某处

> 用途：Coach Mode 的内部判断依据。除非用户明确要求看分析或示范，不整份展示。

## 1. 材料与来源

来源：CTCSOL 官网“备考指南—样题示例—面试（初级）”。核查日期：2026-09-03。

官方页面：https://www.chineseteacher.org.cn/readyExamGuide.do?readyExamFlag=examStructure

材料原文：

> 丽莎：这儿的风景真美啊！
> 林峰：是啊，太美了！咱们把自行车放在这儿，看看风景吧。
> 丽莎：好。这里可以放自行车吗？
> 林峰：当然可以，大家都放在这儿。你先把书包放到旁边的地上，我来给你照张相。
> 丽莎：好啊，你看我这样行吗？
> 林峰：好极了，这个角度特别好！我要照了啊。一、二、三，好了。
> 丽莎：照得怎么样？
> 林峰：你自己看看，照得漂亮极了！
> 丽莎：真漂亮，谢谢你。

官方试讲要求：根据教学设计选择恰当内容，模拟教学场景；包括导入、讲解、操练、活动、板书。

## 2. 内部候选点

这些是供探索的内部候选，不是固定排名。需要根据考生熟悉度、学习者条件和实际设计更新推荐；候选组合也不以本清单为限。

### 候选：把 + 物品 + 放在/放到 + 地点

- 题面依据：“把自行车放在这儿”“把书包放到旁边的地上”。
- 最小范围：处置一个语境中明确的物品，并说明“放”这一动作后的地点结果。
- 适合之处：出现两次；动作可演示；结构可替换；容易形成指令、纠错、角色任务和动态板书。
- 风险：扩展到整个把字句系统；把“放在”和“放到”说成任何场景都完全等同；只写结构而不解释结果意义。
- 内部结论：具备直接题面依据和可操作性；适合能够解释物品处置及地点结果的考生，不因此排除其他候选。

### 可选：动词 + 得 + 状态/程度

- 题面依据：“照得怎么样”“照得漂亮极了”。
- 最小范围：询问和描述动作呈现出的状态或程度。
- 适合之处：有问答对，可形成评价照片的交际活动。
- 风险：材料实例较少；“漂亮极了”内部还含程度表达，七分钟内容容易分叉。
- 内部结论：可选，置信度中。

### 可选：极了

- 题面依据：“好极了”“漂亮极了”。
- 最小范围：形容词 + 极了，表达很高程度。
- 适合之处：形式直观、材料重复。
- 风险：缺少强烈感受的语境时，孤立换词可能生硬；只跟读或替换不足以检查学生能否表达自己的评价。
- 内部结论：可选；能否展开取决于感受表达与交流任务设计，不能仅因形式短而判为内容薄。

### 候选：围绕赞叹或强烈评价组织少量表达

- 题面依据：“真美啊”“太美了”“好极了”“漂亮极了”“真漂亮”。
- 探索方向：能否围绕同一交流目的，选取少量表达让学生观察、选择和回应，而不是逐项讲完所有格式。
- 成立条件：考虑学习者已有形式，明确本课新增目标，核验具体情境中可替换的范围及语气差别。
- 风险：把功能相近说成任何情境都能互换；只做格式互换，没有表达感受的需要。
- 内部结论：值得探索，尚无本项目已核验的组合语法卡；“真坏啊／坏极了”等用户设想需结合语境另行核验，不直接当作教学结论。

用户提出上述或其他合理方案时，给同等的探索机会；依据其实际解释和任务设计讨论取舍，不要求猜中预设首选。

## 3. 共享知识路由

“把 + 物品 + 放在/放到 + 地点”的意义、形式、边界、自然例句和典型偏误只以 `grammar-accuracy-and-sources.md` 中的“首题语法卡：把 + 物品 + 放在/放到 + 地点”为准。确认用户选择该点后读取那张共享卡，不在本案例文件维护另一套语法答案。

本材料需要特别核对两件事：

- 用户的解释是否包含“动作后的地点结果”，而不只说“移动一个东西”；
- 用户是否把范围保持在材料中的“放在/放到某处”，而没有扩展整个把字句系统。

案例中的自行车和书包都是当前场景中双方可以识别的物品。替换例句优先选择能在试讲现场用实物或动作展示的书、手机、水瓶和书包；具体句子从共享语法卡选用或按其边界核验。

## 4. 可行但非唯一的课堂主线

1. 用书包、书或图片创设“准备照相，东西放哪里”的场景。
2. 呈现或回到材料的两句，让学生观察共同成分。
3. 用移动实物突出“动作以后在哪里”，逐步板书结构。
4. 做一轮可见物品与地点的控制替换。
5. 预设一个顺序错误或遗漏地点的学生回答，给具体反馈并让其重说。
6. 进入简短指令任务：一个学生说如何整理拍照区域，另一个执行或复述。

Coach 不应在用户试讲前把这六步一次全部给出。路线图只显示环节名称；用户卡住时才给当前环节动作。用户已经自然讲出后续步骤时，按实际覆盖更新路线，不拉回预设片段。

## 5. 本题提示阶梯

### 找不到教学点

- Level 1：再看看林峰说的两句话，有没有一个出现了两次、而且可以配合移动物品来教的结构？
- Level 2：比较“把自行车放在这儿”和“把书包放到旁边的地上”，它们共同的顺序是什么？
- Level 3：可以选“把 + 物品 + 放在/放到 + 地点”，教物品经过处置以后所在的位置。然后让用户用自己的话重说选点和理由。

### 只说“把字句”，范围太大

- Level 1：这份材料里的两个“把”后面都用了哪个动词？
- Level 2：这节课只围绕“放”来教，你会把结构写成什么？
- Level 3：缩成“把 + 物品 + 放在/放到 + 地点”。然后让用户解释主动舍弃什么。

### 只会说结构，不会说意义

- Level 1：说完这句话以后，自行车或书包发生了什么变化？
- Level 2：重点只是“放”这个动作，还是动作完成后东西在哪里？
- Level 3：本题突出对物品的处置及动作后的地点结果。然后让用户联系一个原句重说。

### 不会设计第一次学生产出

- Level 1：如果你手上有一本书和一个书包，可以让学生完成什么小任务？
- Level 2：你先移动物品，让学生用目标结构告诉你“把什么放在哪里”。
- Level 3：微型示范：“老师把书放在桌子上了。现在请你说：老师把什么放在哪儿？”随后让用户自己继续设计下一问。

## 6. 实际产出观察点

只选择最影响当次表现的 1–3 项反馈：

- 是否把范围缩成“把 + 物品 + 放在/放到 + 地点”；
- 是否讲清动作后的地点结果，而非只念公式；
- 是否从材料或场景引出结构，而非开场直接报语法名称；
- 目标结构呈现前，教师是否允许学生先用已有语言表达，再自然重述目标句；
- 目标结构呈现后，学生是否实际说出完整目标结构；
- 讲解后出现错误时，教师是否给具体线索并让学生完整重说；
- 板书是否随讲解形成；
- 是否把考官当成真实学生等待回答。

没有音频或计时时，不评价语速、发音、停顿和教态。

## 7. 重练后的改善证据

可以认定的可观察改善包括：

- 从“今天讲把字句”改为通过实物或原句引出；
- 从只写公式改为说出“动作以后东西在哪里”；
- 从教师自问自答改为清楚提问、短暂停顿、模拟学生回答和具体反馈；
- 从学生只说地点改为完整说出目标句；
- 从直接公布正确句改为先给局部线索，再请完整重说。

只在用户确实重练同一范围时使用。不要因为换了一套措辞就自动判定改善；必须对应前一遍的聚焦问题。当前环节已基本成立而用户直接继续时，不强行要求重练。

## 8. “教师带着学生练”动作卡示例

用户不知道操练环节要做什么时，可以显示：

**当前位置：** 教师带着学生练（控制性操练）

**本环节要做到：**

- 改变一个物品或地点；
- 让学生独立说出完整目标句；
- 对一次讲解后的典型错误给最小提示。

**可用材料：** 一本书、一个水杯、一张桌子、一个书包。

**完成标志：** 学生至少独立说出一句完整的“把 + 物品 + 放在/放到 + 地点”。

这张卡只在用户卡住时展示，不是固定活动答案。用户可以用自己的物品、场景或连续讲出后续活动。
