# 可教学语法索引

这是经过语法边界复核、可按具体题面调用的教学索引，不是完整 HSK 1–6 清单。每次使用仍须以用户当前材料、学习者水平和七分钟内可教性为准。

## 使用字段

- 教学点与最小范围
- 暂定等级或范围及版本依据
- 来源与材料证据
- 最小可教用法
- 适教理由与风险
- 适用条件与核验提醒

## 有点儿 与 形容词 + 一点儿

- 最小范围：表达当前感受，并提出朝相反或更合适方向调整的要求。
- 暂定等级：需结合实际材料判定，不在本卡固定等级。
- 适用材料：题面中出现 `有点儿 + 形容词`、`形容词 + 一点儿`，或能够形成“当前感受 → 希望调整”对比的材料。
- 最小用法：`有点儿 + 形容词`；比较或调整语境中的 `形容词 + 一点儿`。
- 适教理由：容易形成同一场景下的意义对比、问答、纠错和板书。
- 风险：过度概括褒贬限制；混入 `一点儿 + 名词`；为了成对而造不自然句子。
- 核验提醒：使用前读取 `grammar-accuracy-and-sources.md` 中对应语法卡，并重新核对当前题面和例句自然度。

## 把 + 物品 + 放在/放到 + 地点

- 最小范围：用“把”说明移动物品后的位置结果。
- 暂定等级：需结合所用等级体系及材料判定。
- 材料来源：CTCSOL 官网初级面试样题中的“把自行车放在这儿”“把书包放到旁边的地上”，2026-09-03 核查。
- 适教理由：动作可演示，结果清楚，适合指令、操练、纠错和动态板书。
- 风险：扩展到完整把字句体系会超时；地点介词和趋向补语可能抢走主线。
- 核验提醒：本卡只适用于题面中的“把 + 物品 + 放在/放到 + 地点”；读取 `grammar-accuracy-and-sources.md` 与 `coach-case-ba-placement.md`，不要扩展为完整把字句系统。
