# 可教学语法索引

这是逐步积累的验证索引，不是完整 HSK 1–6 清单。新语法点只有经过材料测试和人工复核后，才能从“待验证”改为“已验证”。

## 记录字段

- 教学点与最小范围
- 暂定等级或范围及版本依据
- 状态：待验证 / 已验证 / 暂停使用
- 来源与材料证据
- 最小可教用法
- 适教理由与风险
- 置信度
- 测试结果与修订记录

## 有点儿 与 形容词 + 一点儿

- 最小范围：表达当前感受，并提出朝相反或更合适方向调整的要求。
- 暂定等级：需结合实际材料判定，不在本卡固定等级。
- 状态：待验证。
- 材料来源：用户旧版备考 PDF 第 7–10 页的相关案例；该旧稿仅用于对照，不作为标准答案。
- 最小用法：`有点儿 + 形容词`；比较或调整语境中的 `形容词 + 一点儿`。
- 适教理由：容易形成同一场景下的意义对比、问答、纠错和板书。
- 风险：过度概括褒贬限制；混入 `一点儿 + 名词`；为了成对而造不自然句子。
- 置信度：中，完成第一轮端到端测试后更新。

## 把 + 物品 + 放在/放到 + 地点

- 最小范围：用“把”说明移动物品后的位置结果。
- 暂定等级：需结合所用等级体系及材料判定。
- 状态：首题内部干跑中；尚未完成真人开口验证。
- 材料来源：CTCSOL 官网初级面试样题中的“把自行车放在这儿”“把书包放到旁边的地上”，2026-09-03 核查。
- 适教理由：动作可演示，结果清楚，适合指令、操练、纠错和动态板书。
- 风险：扩展到完整把字句体系会超时；地点介词和趋向补语可能抢走主线。
- 置信度：语法与题面适配度高；Coach Mode 实际助学效果待真人验证。
- 测试入口：`coach-case-ba-placement.md` 与 `../../tests/fixtures/03-ba-placement-official.md`。
