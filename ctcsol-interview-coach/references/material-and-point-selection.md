# 材料分析与教学点选择

## 1. 恢复材料

先转写截图中的标题、人物、对话、注释和任务要求。保留原句，不先改写。用 `【看不清】` 标记不确定字词，并说明这些缺口是否会影响选点。

## 2. 估计学习者水平

从以下证据综合判断，不只看一个生词：

- 词汇频率与抽象程度
- 句法长度和嵌套程度
- 交际任务复杂度
- 学习者需要理解或产出的形式
- 材料是否显然来自某套已知等级教材

输出“可能的等级或范围 + 2–4 条材料证据 + 置信度”。不知道教材版本时可写“约 HSK 2–3 水平”，不要伪装成精确分级。

## 3. 寻找候选点

候选点可以是：

- 语法：结构和意义边界清楚，材料中有可观察实例。
- 词汇：存在搭配、语用或近义区别，不能只是解释一个词义。
- 交际功能：如提出请求、比较选择、安排位置，能形成可练习的话轮。

每个候选点明确一个可完成的学习目标与意义范围。“最小可教用法”不等于只能教一个格式：可以聚焦“把 + 物品 + 放在/放到 + 地点”，也可以围绕共同交际功能组织少量表达。

用户提出组合教学时，先判断这些表达能否服务同一表达目的、学生是否已有部分形式基础、能否在自然情境中选择使用，再讨论取舍。区分有功能主线的组合教学与逐个罗列语法格式。功能相近不等于所有语境中可替换；具体形式、搭配和语用差别按 `grammar-accuracy-and-sources.md` 核验。未经核验的用户例句保留为设想，不直接写入语法规则。

## 4. 定性比较

结合当前缺口比较，不把下列维度变成必须逐项回答的问卷：

- 题面依据：有哪些直接例句或话轮支持？
- 考生熟悉度：能否准确解释、举例和处理典型错误？不由语气自信程度推断掌握程度。
- 解释难度：意义、形式和使用条件能否讲清？组合教学还要看形式间的联系与边界。
- 自然场景：谁在什么情况下、为了什么目的会这样说？
- 学生产出：当前水平和已有词汇能支持什么任务、互动、纠错与板书？
- 七分钟范围：是否能完成目标，哪些内容需要舍弃？

对正在比较的候选点都说明成立条件和设计难点。简单不等于内容薄，复杂也不等于更有教学价值；结合实际任务判断。教练推荐随用户知识与设计证据更新，不把预设首选当作正确答案。

使用“优先 / 可选 / 不建议”并说明条件与理由，不生成虚假的精确适教分数。这些是内部教学设计建议，不冒充官方选点或评分标准；未确认书名、版本、章节及来源属性的资料保持待核查。

## 5. 根据模式使用分析结果

### 生成参考模式

向用户展示候选点，供其选择；若用户已明确要求直接采用推荐点，可说明假设后继续生成。

### Coach Mode

将材料恢复、水平估计、候选点和首选理由保留为内部教练底稿。先让用户自己发现；需要比较帮助时，可以解释当前候选的一个关键取舍或提供局部情境线索，不把“不展示底稿”误解为不给判断依据。按 `coach-mode.md` 渐进比较，再让用户取舍；用户已有充分理由时直接推进。

## 6. 候选点展示格式

对每个候选点写：

- 候选点与类型
- 材料原句
- 最小可教用法
- 为什么适合本材料
- 主要风险或需要舍弃的范围
- 推荐级别与置信度

最后给一个首选及一句总理由。用户只要求候选分析时停下等待确认；用户已明确要求直接采用推荐点生成时可以继续。Coach Mode 未解锁示范时不展示此候选清单。

## 7. 从使用需要选择课堂主场景

从具体用法的意义出发，找出现实中“谁、在什么情况下、为了什么目的”使用它，再结合学习者已有词汇、水平、道具及课堂条件选择主场景。自然不等于有统计依据的“最常见”；没有语料依据不作频率排名，也不为整个语法系统规定唯一最佳场景。

场景应让目标表达有使用理由，并支持导入、操练、活动和检查持续展开。相关场景变化可以用于迁移；不要为了换词而不断切换无关图片。每一步应让学生逐渐减少依赖、增加表达或选择的空间。如果安排两轮操练，需说明第二轮相比第一轮增加了什么，而不是改名重复。轮数与具体递进方式按教学目标决定，不机械固定为一种模板。

检查语法正确性与情境适切性时分开判断。例如“把凳子放到桌子上”在打扫背景下可以自然成立；缺少背景时应先探明目的，而非判错。“整理房间”也不是天然有效：仍需让学生产生信息、选择或合作需要，并检查任务结果能否反映目标语言的运用。任务不必都要求动作执行，评价、请求、协商等用法有各自合适的成果。
