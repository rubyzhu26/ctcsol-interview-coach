# 材料分析与教学点选择

## 1. 恢复材料

先转写截图中的标题、人物、对话、注释和任务要求。保留原句，不先改写。用 `【看不清】` 标记不确定字词，并说明这些缺口是否会影响选点。

## 2. 估计学习者水平

从以下证据综合判断，不只看一个生词：

- 词汇频率与抽象程度
- 句法长度和嵌套程度
- 交际任务复杂度
- 学习者需要理解或产出的形式
- 材料是否显然来自某套已知等级教材

输出“可能的等级或范围 + 2–4 条材料证据 + 置信度”。不知道教材版本时可写“约 HSK 2–3 水平”，不要伪装成精确分级。

## 3. 寻找候选点

候选点可以是：

- 语法：结构和意义边界清楚，材料中有可观察实例。
- 词汇：存在搭配、语用或近义区别，不能只是解释一个词义。
- 交际功能：如提出请求、比较选择、安排位置，能形成可练习的话轮。

每个候选点先缩成一个“最小可教用法”。例如不是笼统讲“把字句”，而是讲“把 + 物品 + 放在/放到 + 地点”。

## 4. 定性比较

依次检查：

1. 题面依据是否直接；
2. 七分钟内能否缩小范围；
3. 能否用少量语言讲清形式、意义和条件；
4. 能否设计由易到难的互动；
5. 是否能展示纠错和动态板书；
6. 是否匹配学习者水平。

使用“优先 / 可选 / 不建议”并说明理由，不生成虚假的精确适教分数。

## 5. 根据模式使用分析结果

### 生成参考模式

向用户展示候选点，供其选择；若用户已明确要求直接采用推荐点，可说明假设后继续生成。

### Coach Mode

将材料恢复、水平估计、候选点和首选理由保留为内部教练底稿。先让用户自己发现、选择和说明理由；遗漏时使用 `coach-mode.md` 的提示阶梯。用户提出合理的非首选点时，按题面依据和可教性评估，不强迫其猜中首选。

## 6. 候选点展示格式

对每个候选点写：

- 候选点与类型
- 材料原句
- 最小可教用法
- 为什么适合本材料
- 主要风险或需要舍弃的范围
- 推荐级别与置信度

最后给一个首选及一句总理由。用户只要求候选分析时停下等待确认；用户已明确要求直接采用推荐点生成时可以继续。Coach Mode 未解锁示范时不展示此候选清单。
